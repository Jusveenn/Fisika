# ⚛ Physics Hub

**Platform belajar fisika SMA modern, lengkap, dan interaktif.**

> Versi 1.0.0 · HTML + CSS + Vanilla JavaScript · Gratis & Open Source

---

## 🚀 Cara Menjalankan

Tidak perlu server atau instalasi apapun. Cukup:

1. Buka folder `Physics-Hub/`
2. Double-click `index.html`
3. Website langsung terbuka di browser

---

## 📁 Struktur Project

```
Physics-Hub/
├── index.html          # Halaman utama (semua section)
├── style.css           # Semua styling (dark/light theme, animasi, responsif)
├── script.js           # Semua logika interaktif
├── assets/
│   ├── images/         # Gambar (opsional)
│   ├── icons/          # Ikon kustom (opsional)
│   └── sounds/         # Efek suara (opsional)
└── README.md           # Dokumentasi ini
```
